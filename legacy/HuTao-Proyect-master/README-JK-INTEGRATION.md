# HuTao-Proyect dentro de JK-Bot-MD

Este directorio contiene la copia completa del proyecto adjunto, preservada como referencia para una futura adaptación de comandos al núcleo **JK Bot / Mod Biyakudochi**.

No ejecutar este proyecto desde la raíz de JK-Bot-MD ni reemplazar sus archivos de arranque. La integración funcional debe hacerse adaptando módulos a `commands/` y registrándolos en el dispatcher actual.

Consulta [`docs/HUTAO_INTEGRATION.md`](../../docs/HUTAO_INTEGRATION.md) para el inventario y las decisiones de compatibilidad.
